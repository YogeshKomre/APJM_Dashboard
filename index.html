APJM Dashboard

Cisco Finesse Call Monitoring System

A full-stack application for monitoring Cisco Finesse for wrong number dialing.

Backend Features

  • Express.js Server: RESTful API with authentication
  • Socket.IO: Real-time communication for live notifications
  • MongoDB Integration: Data persistence for users and notifications
  • JWT Authentication: Secure user sessions
  • CORS Support: Cross-origin resource sharing

API Endpoints

  • /api/auth - User authentication
  • /api/agents - Agent management
  • /api/notifications - Notification handling

Running the Full Application

To run the complete APJM Dashboard with backend functionality:

  1. Clone the repository: git clone https://github.com/YogeshKomre/APJM_Dashboard.git
  2. Install dependencies: npm run install-all
  3. Set up environment variables in .env file
  4. Start both frontend and backend: npm run dev-all

Note: This GitHub Pages site only hosts the frontend. For full functionality, the backend server needs to be running locally or deployed separately.
